# MiniMidi v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Android app that turns a foldable phone into a 16-pad, velocity-sensitive USB MIDI drum controller that any macOS DAW sees as a class-compliant MIDI device.

**Architecture:** One Activity, one Compose screen. Pure-Kotlin units (`Pad`/`DEFAULT_PADS`, MIDI byte encoding, `velocity()`, `PadEngine`, grid geometry) hold all the logic and are JVM-unit-tested. Thin Android glue (`MidiOut`, `Haptics`, `Settings` persistence, `PadScreen`, `MainActivity`) wires them to `MidiManager`, the vibrator, `SharedPreferences` and raw `MotionEvent`s. Touch → MIDI is a synchronous call chain on the main thread with no queues.

**Tech Stack:** Kotlin (AGP 9 built-in Kotlin 2.3.20), Jetpack Compose (BOM 2026.03.01) + Material3 (sliders/switches only), `android.media.midi`, JUnit 4. Mac-side end-to-end check: Python 3 + `mido` + `python-rtmidi`.

**Spec:** `docs/superpowers/specs/2026-09-30-minimidi-design.md`. Read it before starting any task.

## Review Focus

1. **Device reports no contact size** (`getTouchMajor` = 0 or NaN, and every `adb input tap`): pads must still play, at the fixed-velocity value, not silently at velocity 1. Pinned in Task 3 (`zeroContactFallsBackToFixedValue`, `nanContactFallsBackToFixedValue`).
2. **Pad set changes while a finger is down** (fold into big-pads mode, or a future remap/bank): lifting the finger must send note-off for the note that was pressed. Pinned in Task 4 (`releaseUsesPadCapturedAtPress`).
3. **Missed UP for a pointer ID** (the same pointer ID goes DOWN twice): the first note must be turned off, not left hanging. Pinned in Task 4 (`pressingSamePointerTwiceTurnsOffFirstNote`).
4. **System steals the gesture** (`ACTION_CANCEL`, e.g. an edge swipe or the settings panel opening mid-hold): every held note must turn off. Pinned in Task 4 (`releaseAllTurnsOffEveryHeldNote`).
5. **Touch on or beyond the grid edge / zero-size grid before first layout**: a touch on the last pixel plays the edge pad, a touch outside plays nothing, and nothing crashes. Pinned in Task 5 (`hitOutsideIsNull`, `hitOnFarEdgeClampsToEdgePad`, `zeroSizeGridHitsNothing`).

```kotlin
package com.example.minimidi

/** One pad's output. [channel] is 1-based, as musicians and DAWs show it (10 = GM drums). */
data class Pad(val note: Int, val channel: Int, val label: String)

// General MIDI drum map, notes 36..51, so each label is what a GM kit (and Logic's kits) plays.
private val LABELS = listOf("BD", "RS", "SD", "CP", "SD2", "FT", "CH", "FT2", "PH", "LT", "OH", "MT", "MT2", "CY", "HT", "RD")

// ponytail: fixed table for v1. Remapping and banks will edit this list, not the code that reads it.
val DEFAULT_PADS: List<Pad> = LABELS.mapIndexed { i, label -> Pad(note = 36 + i, channel = 10, label = label) }
```

and `Midi.kt`

```kotlin
package com.example.minimidi

// Raw MIDI 1.0 channel messages. Channel is 1-based (1..16).
fun noteOn(channel: Int, note: Int, velocity: Int) = message(0x90, channel, note, velocity)
fun noteOff(channel: Int, note: Int) = message(0x80, channel, note, 0)
fun allNotesOff(channel: Int) = message(0xB0, channel, 123, 0)

private fun message(status: Int, channel: Int, data1: Int, data2: Int): ByteArray {
    require(channel in 1..16 && data1 in 0..127 && data2 in 0..127) { "bad MIDI message: ch=$channel $data1 $data2" }
    return byteArrayOf((status or (channel - 1)).toByte(), data1.toByte(), data2.toByte())
}
```

```kotlin
package com.example.minimidi

import kotlin.math.roundToInt

const val SENSITIVITY_MIN = 1
const val SENSITIVITY_MAX = 10

// Softest real hit. Velocity 1 is near-silent in Logic's kits; hardware pads keep a floor too. Tuned in the Task 10 feel check.
const val MIN_VELOCITY = 20

// Contact diameters below this are treated as the softest hit.
private const val FLOOR_DP = 25f

/**
 * Touch contact diameter (dp, from MotionEvent.getTouchMajor) → MIDI velocity MIN_VELOCITY..127.
 * Higher sensitivity means a smaller contact reaches full velocity.
 * Devices that report no usable contact size (≤ 1 dp, or NaN) get [fixedValue], so pads never go silent.
 */
fun velocity(contactDp: Float, sensitivity: Int, fixed: Boolean, fixedValue: Int): Int {
    val fallback = fixedValue.coerceIn(1, 127)
    if (fixed || contactDp.isNaN() || contactDp <= 1f) return fallback
    val s = sensitivity.coerceIn(SENSITIVITY_MIN, SENSITIVITY_MAX)
    // ponytail: linear curve; the sensitivity slider is the per-device calibration knob. Add a curve setting if feel demands it.
    val fullScaleDp = 100f - 6f * s // s=1 → 94 dp, s=10 → 40 dp
    val t = ((contactDp - FLOOR_DP) / (fullScaleDp - FLOOR_DP)).coerceIn(0f, 1f)
    return (MIN_VELOCITY + t * (127 - MIN_VELOCITY)).roundToInt()
}
```

```kotlin
package com.example.minimidi

/**
 * Tracks which pad each finger pressed and emits MIDI bytes through [send].
 * Note-off always uses the Pad captured at press time, so remaps, banks or fold changes mid-hit can't leave notes stuck.
 */
class PadEngine(private val send: (ByteArray) -> Unit) {
    private val held = HashMap<Int, Pad>()

    fun press(pointerId: Int, pad: Pad, velocity: Int) {
        release(pointerId) // a missed UP must not leave the old note hanging
        held[pointerId] = pad
        send(noteOn(pad.channel, pad.note, velocity.coerceIn(1, 127)))
    }

    fun release(pointerId: Int) {
        held.remove(pointerId)?.let { send(noteOff(it.channel, it.note)) }
    }

    fun releaseAll() {
        held.values.forEach { send(noteOff(it.channel, it.note)) }
        held.clear()
    }

    /** App leaving the foreground: note-offs for held pads, then All Notes Off on every channel in use. */
    fun panic(channels: Collection<Int>) {
        val all = (channels + held.values.map { it.channel }).distinct()
        releaseAll()
        all.forEach { send(allNotesOff(it)) }
    }
}
```

```kotlin
package com.example.minimidi

data class GridLayout(val columns: Int, val rows: Int) {
    val padCount get() = columns * rows
}

val FULL_GRID = GridLayout(columns = 4, rows = 4)
val BIG_PADS_GRID = GridLayout(columns = 2, rows = 4)

fun layoutFor(folded: Boolean, bigPadsWhenFolded: Boolean) =
    if (folded && bigPadsWhenFolded) BIG_PADS_GRID else FULL_GRID

/** 0-based pad index for a cell; visual row 0 is the top. Pad 0 sits bottom-left, MPC style. */
fun padIndex(visualRow: Int, column: Int, layout: GridLayout) =
    (layout.rows - 1 - visualRow) * layout.columns + column

/** Pad under (x, y) in a [width]×[height] px grid of equal cells, or null outside it. Gutters belong to their cell. */
fun hitTest(x: Float, y: Float, width: Float, height: Float, layout: GridLayout): Int? {
    if (width <= 0f || height <= 0f || x < 0f || y < 0f || x > width || y > height) return null
    // Clamp: x == width (last pixel) belongs to the last column, not outside.
    val column = (x / width * layout.columns).toInt().coerceAtMost(layout.columns - 1)
    val visualRow = (y / height * layout.rows).toInt().coerceAtMost(layout.rows - 1)
    return padIndex(visualRow, column, layout)
}

/** Colour group 0..3 (red, orange, yellow, cream): the pad's row in the full 4×4 kit, so colours don't shift in big-pads mode. */
fun colourGroup(padIndex: Int) = padIndex / 4
```

```kotlin
package com.example.minimidi

import android.content.Context
import android.media.midi.MidiDevice
import android.media.midi.MidiDeviceInfo
import android.media.midi.MidiInputPort
import android.media.midi.MidiManager
import android.os.Handler
import android.os.Looper
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.setValue
import java.io.IOException

/**
 * Sends MIDI to the computer over USB. With the phone's USB mode set to "MIDI", the host appears here as a
 * TYPE_USB device whose *input* port is what we write to (ports are named from the device's point of view).
 * This is the one seam a future Bluetooth output plugs in beside.
 */
class MidiOut(context: Context) {
    var connected by mutableStateOf(false)
        private set

    private val manager = context.getSystemService(MidiManager::class.java)
    private val handler = Handler(Looper.getMainLooper())
    private var device: MidiDevice? = null
    private var port: MidiInputPort? = null
    private var opening = false
    private var started = false // openDevice is async: a callback landing after stop() must not reopen

    private val callback = object : MidiManager.DeviceCallback() {
        override fun onDeviceAdded(info: MidiDeviceInfo) = openIfUsb(info)
        override fun onDeviceRemoved(info: MidiDeviceInfo) {
            if (device?.info?.id == info.id) close()
        }
    }

    // ponytail: the pre-API-33 overloads work on every supported version; move to the transport/executor overloads if they're removed.
    @Suppress("DEPRECATION")
    fun start() {
        started = true
        manager.registerDeviceCallback(callback, handler)
        manager.devices.forEach(::openIfUsb)
    }

    fun stop() {
        started = false
        manager.unregisterDeviceCallback(callback)
        close()
    }

    /** Never throws: a failed write (cable yanked mid-send) just marks us disconnected. */
    fun send(bytes: ByteArray) {
        val p = port ?: return
        try {
            p.send(bytes, 0, bytes.size)
        } catch (e: IOException) {
            close()
        }
    }

    // A phone acting as a USB peripheral can't host another USB MIDI device at the same time,
    // so the first USB device with an input port is the computer.
    private fun openIfUsb(info: MidiDeviceInfo) {
        if (!started || device != null || opening || info.type != MidiDeviceInfo.TYPE_USB || info.inputPortCount == 0) return
        opening = true
        manager.openDevice(info, { d ->
            opening = false
            // Close anything we won't keep: a device held without a port would block every later reconnect.
            val p = if (started) d?.openInputPort(0) else null // null if another app holds the port
            if (d == null || p == null) {
                d?.close()
                return@openDevice
            }
            device = d
            port = p
            connected = true
        }, handler)
    }

    private fun close() {
        port?.close()
        device?.close()
        port = null
        device = null
        connected = false
    }
}
```

```kotlin
package com.example.minimidi

import android.content.Context
import android.os.VibrationEffect
import android.os.VibrationEffect.Composition.PRIMITIVE_CLICK
import android.os.VibratorManager

/** A short, crisp tick per hit, scaled by velocity. Silent on vibrators without haptic primitives. */
class Haptics(context: Context) {
    private val vibrator = context.getSystemService(VibratorManager::class.java).defaultVibrator
    private val supported = vibrator.areAllPrimitivesSupported(PRIMITIVE_CLICK)

    fun tick(velocity: Int) {
        if (!supported) return
        vibrator.vibrate(VibrationEffect.startComposition().addPrimitive(PRIMITIVE_CLICK, velocity.coerceIn(1, 127) / 127f).compose())
    }
}
```

```kotlin
@OptIn(ExperimentalComposeUiApi::class)
@Composable
private fun PadGrid(
    layout: GridLayout,
    settings: Settings,
    engine: PadEngine,
    haptics: Haptics,
    enabled: Boolean,
    modifier: Modifier,
) {
    // pointerId → (padIndex, velocity 0..1). Plain map, not Compose state: only the per-pad levels below recompose.
    val fingers = remember { HashMap<Int, Pair<Int, Float>>() }
    // One state per pad, so a hit recomposes only the pad that was hit. A pad is lit while any finger holds it.
    val padLevels = remember { List(DEFAULT_PADS.size) { mutableStateOf<Float?>(null) } }
    fun refresh(pad: Int) {
        padLevels[pad].value = fingers.values.filter { it.first == pad }.maxOfOrNull { it.second }
    }
    fun releaseAll() {
        engine.releaseAll()
        fingers.clear()
        padLevels.forEach { it.value = null }
    }
    val density = LocalDensity.current.density
    var size by remember { mutableStateOf(IntSize.Zero) }
    val currentSettings by rememberUpdatedState(settings)
    val currentLayout by rememberUpdatedState(layout)
    val currentEnabled by rememberUpdatedState(enabled)

    LaunchedEffect(enabled) {
        if (!enabled) releaseAll()
    }

    Column(
        modifier
            .fillMaxWidth()
            .onSizeChanged { size = it }
            .systemGestureExclusion() // edge pads shouldn't trigger Back; Android caps this at 200 dp per edge (checked in Task 10)
            .pointerInteropFilter { e ->
                // Raw MotionEvents: Compose's pointer API doesn't expose touch size, which velocity needs.
                if (!currentEnabled) return@pointerInteropFilter false
                when (e.actionMasked) {
                    MotionEvent.ACTION_DOWN, MotionEvent.ACTION_POINTER_DOWN -> {
                        val i = e.actionIndex
                        val pad = hitTest(e.getX(i), e.getY(i), size.width.toFloat(), size.height.toFloat(), currentLayout)
                        if (pad != null) {
                            val s = currentSettings
                            val v = velocity(e.getTouchMajor(i) / density, s.sensitivity, s.fixedVelocity, s.fixedValue)
                            val id = e.getPointerId(i)
                            engine.press(id, DEFAULT_PADS[pad], v)
                            fingers.remove(id)?.let { refresh(it.first) } // stale entry from a missed UP
                            fingers[id] = pad to v / 127f
                            refresh(pad)
                            if (s.haptics) haptics.tick(v)
                        }
                    }
                    MotionEvent.ACTION_POINTER_UP -> {
                        val id = e.getPointerId(e.actionIndex)
                        engine.release(id)
                        fingers.remove(id)?.let { refresh(it.first) }
                    }
                    // Last finger lifted: nothing may stay held, whatever events were missed.
                    MotionEvent.ACTION_UP, MotionEvent.ACTION_CANCEL -> releaseAll()
                    // ACTION_MOVE ignored on purpose: sliding onto another pad doesn't trigger it.
                }
                true
            },
    ) {
        for (row in 0 until layout.rows) {
            Row(Modifier.weight(1f)) {
                for (column in 0 until layout.columns) {
                    val index = padIndex(row, column, layout)
                    PadCell(index, padLevels[index], Modifier.weight(1f).fillMaxHeight().padding(3.dp))
                }
            }
        }
    }
}

@Composable
private fun PadCell(index: Int, level: State<Float?>, modifier: Modifier) {
    val pad = DEFAULT_PADS[index]
    val velocity = level.value // read here, not in PadGrid, so a hit recomposes only this pad
    val lit = velocity != null
    // Instant on (snap), 150 ms linear fade on release. No ripple.
    val glow = animateFloatAsState(
        targetValue = if (velocity != null) 0.25f + 0.4f * velocity else 0f,
        animationSpec = if (lit) snap() else tween(durationMillis = 150, easing = LinearEasing),
        label = "pad$index",
    )
    val base = Rhythm.Groups[colourGroup(index)]
    Box(
        modifier
            .semantics { contentDescription = "Pad ${index + 1}, ${pad.label}" }
            .clip(PadShape)
            .drawBehind {
                // glow is read in the draw phase: the fade redraws each frame without recomposing.
                drawRect(lerp(base, Color.White, glow.value))
                // Stroke is centred on the edge and the clip hides the outer half, so 4 dp draws 2 dp inside.
                if (lit) drawRect(Color.White, style = Stroke(width = 4.dp.toPx()))
            },
    ) {
        val ink = Color.Black.copy(alpha = 0.55f)
        Text("${index + 1}", Modifier.align(Alignment.TopStart).padding(6.dp), style = Rhythm.label(ink))
        Text(pad.label, Modifier.align(Alignment.BottomEnd).padding(6.dp), style = Rhythm.label(ink))
    }
}
```

```python
#!/usr/bin/env python3
"""End-to-end check: tap every visible pad via adb and assert the matching MIDI arrives on this Mac.

Usage:  .venv/bin/python tools/e2e_midi.py [port-substring]
Phone:  USB mode = MIDI, USB debugging on, MiniMidi in the foreground, settings panel closed.
"""
import os
import re
import shutil
import subprocess
import sys
import time
import xml.etree.ElementTree as ET

import mido

ADB = os.environ.get("ADB") or shutil.which("adb") or os.path.expanduser("~/Library/Android/sdk/platform-tools/adb")
FIRST_NOTE = 36
CHANNEL = 9  # mido channels are 0-based: 9 is MIDI channel 10


def adb(*args):
    return subprocess.run([ADB, *args], check=True, capture_output=True, text=True).stdout


def visible_pads():
    """{pad number: (x, y) centre in screen px}, read from the accessibility tree."""
    adb("shell", "uiautomator", "dump", "/sdcard/minimidi-ui.xml")
    root = ET.fromstring(adb("exec-out", "cat", "/sdcard/minimidi-ui.xml"))
    pads = {}
    for node in root.iter("node"):
        m = re.match(r"Pad (\d+),", node.get("content-desc", ""))
        if m:
            x1, y1, x2, y2 = map(int, re.findall(r"\d+", node.get("bounds")))
            pads[int(m.group(1))] = ((x1 + x2) // 2, (y1 + y2) // 2)
    return pads


def open_port(hint):
    names = mido.get_input_names()
    matches = [n for n in names if hint.lower() in n.lower()]
    if len(matches) != 1:
        sys.exit(f"Need exactly one MIDI input matching {hint!r}; found {matches}. All inputs: {names}")
    return mido.open_input(matches[0])


def wait_for(port, backlog, kind, note, timeout=1.0):
    """Keep every received message in `backlog` so a later wait can still find it."""
    end = time.monotonic() + timeout
    while time.monotonic() < end:
        backlog.extend(port.iter_pending())
        for i, msg in enumerate(backlog):
            if msg.type == kind and msg.note == note:
                return backlog.pop(i)
        time.sleep(0.002)
    return None


def main():
    hint = sys.argv[1] if len(sys.argv) > 1 else ""
    pads = visible_pads()
    if len(pads) < 8:
        sys.exit(f"Expected at least 8 pads on screen, found {sorted(pads)}")
    failures = []
    with open_port(hint) as port:
        for _ in port.iter_pending():
            pass  # drain anything stale
        backlog = []
        for pad, (x, y) in sorted(pads.items()):
            note = FIRST_NOTE + pad - 1
            adb("shell", "input", "tap", str(x), str(y))
            on = wait_for(port, backlog, "note_on", note)
            off = wait_for(port, backlog, "note_off", note)
            print(f"pad {pad:2d}  on={on}  off={off}")
            if on is None:
                failures.append(f"pad {pad}: no note_on for note {note}")
            elif on.channel != CHANNEL or not 1 <= on.velocity <= 127:
                failures.append(f"pad {pad}: bad note_on {on}")
            if off is None:
                failures.append(f"pad {pad}: no note_off for note {note}")
    if failures:
        print("\n".join(["FAIL"] + failures))
        sys.exit(1)
    print(f"OK: {len(pads)} pads → notes {FIRST_NOTE}..{FIRST_NOTE + max(pads) - 1} on channel 10")


if __name__ == "__main__":
    main()
```
